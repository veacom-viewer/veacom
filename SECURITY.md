# Security reports

Report suspected vulnerabilities privately to the `veacom-viewer/veacom` maintainers through an existing private contact channel. If GitHub offers **Security → Report a vulnerability** for this repository, that private reporting form is also suitable. Do not open a public issue or publish exploit details before coordination with the owner.

Include the affected commit or version, platform, impact, and a synthetic reproduction. Do not send patient data, credentials, images from a clinical system, or tokens. Ask the owner for an agreed private transfer method if a reproduction needs sensitive material.

See `docs/imaging-security.md` for the Electron broker and engine boundary. Changes to that boundary, decoding, archive handling, updates, or telemetry require explicit security review and relevant regression evidence.
